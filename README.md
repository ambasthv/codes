Floor = -0.63 | Cap = 0.01

“Here, we see a fairly clear inverse relationship between the ratio and default rate — as the ratio increases, the default rate generally comes down. At the lower end, particularly below around -0.63, default rates are materially higher, so we treat that as the highest-risk region and set the floor at -0.63. The default rate continues to decline through the middle of the distribution, but once we get to around 0.01, it is already relatively low and the remaining movement becomes more variable rather than showing a consistent further reduction. So we set 0.01 as the cap. Essentially, we’re retaining the meaningful relationship while avoiding additional differentiation at the extreme ends.”
